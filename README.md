# VYRE

Free, open-source gaming network diagnostics and safe local optimization.

Windows first, Linux second. Built with Tauri 2, Rust, React, TypeScript, and SQLite.

**Status:** The 0.1.0 foundation is being implemented. Current features are diagnostic only; this is not a VPN, relay, or guaranteed ping reducer.
